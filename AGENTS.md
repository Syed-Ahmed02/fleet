## Desktop apps

- Drive desktop apps with the `agent-desktop` CLI (installed by `install.sh`). Run `agent-desktop skills get desktop` and `agent-desktop skills get platform` before your first command, because the CLI's own guide matches its version.
- Use the harness's built-in computer use only when the task needs pixels: a visual check, a canvas, or an app whose accessibility tree is empty.
